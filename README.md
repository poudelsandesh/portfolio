# Sandesh Poudel — Portfolio

All website files are in this one folder. No build tools or asset folders are required.

## Upload to GitHub Pages
1. Extract the ZIP on your computer.
2. Open your portfolio repository on GitHub.
3. Click Add file → Upload files. Select ALL extracted files together, including the HTML, CSS, JavaScript, pictures, logos, and PDF. Upload the files themselves, not the ZIP or an enclosing folder.
4. Commit the upload to main.
5. In Settings → Pages, choose Deploy from a branch, then main and / (root). Save.
6. Wait for the Pages deployment to finish, then open https://poudelsandesh.github.io/portfolio/ and refresh.

index.html must appear at the repository root. File names are case-sensitive. If a previous upload included a Word CV, it may be deleted; the website now links only to Sandesh_Poudel_CV.pdf.
